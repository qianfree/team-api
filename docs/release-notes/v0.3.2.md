## ⚠️ 升级须知（行为变更）

### 1. 文件上传默认白名单与大小上限收紧（`internal/logic/relay/files.go`）

为治理 SSRF/存储滥用面，开放文件上传端点的**默认**配置收紧为安全基线，存量部署升级后若无显式配置，行为会变化：

- **默认允许的扩展名**：`jsonl / json / txt / csv / md / pdf` + 常见图片格式。**不再默认放行**音频、视频、`docx`、`srt` 等扩展——batch 场景的大 JSONL、字幕/文档类上传若被默认拒绝，属预期收紧。
- **默认单文件大小上限**：`relay_files_max_size_mb <= 0` 原语义为「不限制」，现回退为 **32MB**（"0 = 不限制"旋钮失效，防止误配为 0 打开无限上传）。

**需要旧场景继续可用的部署**：升级后显式配置系统设置项 `relay_files_allowed_types`（补充所需扩展名）与 `relay_files_max_size_mb`（按业务上限设置）即可，无需改代码。

## 🔧 运维 / 可观测性改进

- **长驻后台循环 panic 自愈**：钱包物化器、缓存/配置失效订阅、渠道目录刷新/订阅、调度策略刷新、维护循环、健康上报、JS 插件失效订阅、webhook sweep/cleanup、监控采样器等进程级长驻循环，panic 后按指数退避（5s → 60s 封顶）自动重启，不再静默永久降级；此前仅记录一条 Error 日志。异步任务轮询因 worker 持有 WaitGroup 计数不适用重启，走下条逐轮 Guard 保护。
- **逐条 Guard 保护**：webhook 投递 worker、内容过滤审计落库 worker、异步任务轮询单轮，单条/单轮异常只丢当次，worker 存活继续消费。
- **golangci-lint CI 版本固定**（v2.15，与本地开发版本一致），避免 action 默认装最新版导致规则口径漂移；gofmt 门禁覆盖范围补齐 `tests/`、`scripts/`。
