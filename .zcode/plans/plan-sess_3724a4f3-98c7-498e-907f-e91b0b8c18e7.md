# 工具调用计费（联网搜索/云端工具按次附加费）实施方案

## Context

请求大模型时若触发联网搜索（Claude web_search、Gemini googleSearch、OpenAI web_search）等云端工具，上游按次收费，但 team-api 目前只结算模型本身的 token/按次/阶梯/公式费用，**工具调用费完全漏收**。

参考 new-api 的「工具附加费（tool surcharge）」设计：渠道层从响应中**数出**各工具调用次数 → 全局工具价格表（工具名[+模型前缀]→单价）查价 → 结算时附加到**任何计费模式**之上 → 快照明细留痕。

已确认的决策：
- **全局工具价格表**（new-api 式，存 `sys_options`，支持 `工具名:模型前缀*` 匹配 + 内置种子价），不放入 mdl_pricing
- **P0 采集范围**：Claude（server_tool_use 报数）、Gemini（grounding 查询数）、OpenAI Responses（web_search_call 项）

## 数据流总览

```
请求 → PreDeduct（不变：不含工具费，调用次数事前未知，与 new-api 一致）
 ↓
渠道 adaptor DoResponse：从响应提取工具证据 → usage.ToolCalls{工具名:次数}
 ↓
SettleWithUsage：computeCostWithEval 照旧算模型费用
  + 附加费 = Σ min(次数,10000) × 单价(工具,模型前缀匹配) × 租户乘数 × 时段乘数
  → TotalCost = 模型费 + 工具附加费 → calcSettlementDiff 补差 → executeSettlement
  （settleClaimLua 全额扣款允许负余额，wallet.go:436 已验证，补差链路现成）
 ↓
快照 billing_snapshot.tool_surcharges + 摘要行；bil_usage_logs 新列 tool_usage/tool_surcharge_cost
```

## 改动明细

### 1. 全局工具价格表 — 新文件 `internal/logic/billing/tool_pricing.go`

- `internal/logic/common/settings_registry.go`：新增分类 `{Key:"billing", Label:"计费配置"}` + key `tool_call_prices`（SettingTypeJSON，默认 `"{}"`）
- 内存形态 `Prices map[string]float64`，key 格式 `工具名` 或 `工具名:模型前缀*`，**单价单位=每次调用 USD**（new-api $/1K ÷1000，无隐藏换算）
- **内置种子价**（换算自 new-api `setting/operation_setting/tools.go` 种子表）：`web_search=0.01`、`google_search=0.014`（`google_search:gemini-2.5*|2.0*|1.5*` 置 0 免费）、`google_search_grounded_prompt=0.035`、`file_search=0.0025`、`code_execution=0.05`、`web_fetch=0.05`、`search_std=0.01`/`search_pro=0.03`（zhipu，P1 采集后即生效）。管理端 JSON 覆盖种子，**置 0=关闭该工具计费**；种子价部署即生效
- `LoadToolPrices(ctx)`：`Config().GetOptionJSON` + 种子合并 → 索引 `{defaults map, prefixes 按前缀长度降序}`；索引缓存 `{raw string, index}` atomic 替换，raw 未变零重建（ConfigService 自带缓存+pub/sub 失效）
- `Resolve(tool, model)`：`tool:模型前缀*` 最长匹配 → 工具默认价 → 0（免费）
- 管理端校验：`internal/logic/admin/settings.go` validateCrossFieldSettings 增 "billing" 分支：JSON 可解析、key 匹配 `^[a-z0-9_]+(:[A-Za-z0-9.*\-]+)?$`、价格 ≥0 且 ≤100

## 关键语义决策

1. 单价=每次调用 USD（非 new-api 的 $/1K 口径）
2. 查找：`工具名:模型前缀*` 最长匹配 → 工具默认 → 0=免费；种子价部署即生效，置 0 关闭
3. 附加费乘 租户乘数×时段乘数（与模型费同乘数链，对齐 new-api 的 groupRatio）
4. 预扣不含工具费，结算补差（负余额允许，链路已验证）
5. 每工具计数上限 10000；流中断按已见计数
6. 部署顺序：先代码后改配置即安全；种子价随部署立即生效（符合"要扣费"的意图，可置 0 关闭）
